# 稳镜 Steadicam（抗 3D 眩晕 Fabric mod）

给玩 Minecraft 会 3D 眩晕的玩家：一键关掉视角摇晃、受伤歪屏、FOV 缩放、传送门/恶心屏幕扭曲和暗角，并在屏幕上画一条**永远不动的地平线参考线**。所有改动都能一键逐项还原。

**纯客户端 Fabric mod，不写任何 mixin** —— 这是它敢和大型整合包共存的原因，见下文。

| | |
|---|---|
| 游戏版本 | Minecraft **26.2**（`~26.2`，26.3 亦可） |
| 加载器 | Fabric Loader ≥ 0.19，需要 Fabric API |
| 环境 | 仅客户端 |
| 体积 | 约 24 KB |
| 许可 | MIT |

## 安装

把 `steadicam-1.0.0+26.2.jar` 放进整合包的 `mods` 文件夹即可，无需任何配置：首次进游戏自动生效，并在屏幕上提示一次。

## 怎么用

- **F7** —— 游戏内一键开关。关掉时会把改过的选项**逐项还原**成你原来的值。按键可在 设置 → 按键设置 → 稳镜 里改（注意：原版在打开任何界面时不分发模组快捷键，所以要在游戏里按）。
- **模组菜单 → 稳镜 → 配置** —— 总开关、档位、参考线样式、线条浓度，以及「重新应用当前档位」「恢复原设置并关闭」。
- 配置文件：`config/steadicam.json`；首次接管前还会整份备份 `config/steadicam/options.txt.bak`。

### 档位

| 档位 | 关掉的东西 |
|---|---|
| 弱 | 视角摇晃、受伤歪屏、FOV 缩放（疾跑/拉弓时视野不再突然拉宽） |
| **标准（默认）** | 以上 + 屏幕扭曲（传送门/水下/恶心）、暗角、黑暗效果 |
| 最强 | 以上 + 帧率上限 120、附魔光效、区块淡入、矿车镜头翻转 |

### 参考线

默认「地平线 + 中心锚点」。它按相机矩阵实时投影，所以永远压在真正的天地线上，俯仰、转向、侧滚都跟得上；`F1` 隐藏 HUD 时一起隐藏。原理是给大脑一个不动的参照物——现实里你不晕是因为视野里有静止的东西，而 MC 的画面里没有一个像素不动。

## 为什么不与整合包冲突

Minecraft 26.x 已经把这些眩晕源全部做成了**官方无障碍选项**，并且每帧被 `GameRenderer` 读进 `OptionsRenderState`（`bobView` / `damageTiltStrength` / `screenEffectScale` 等字段可在客户端 jar 里直接验证）。也就是说：翻这些开关就够了，**不需要改渲染管线**。

这一点很关键：大型整合包里 `Camera` / `GameRenderer` / `ScreenEffectRenderer` / `InGameHud` 早已被 Iris、Sodium、Tweakeroo、ReplayMod 反复注入，实测在 185 个 mod 的包日志里就能看到一条现成的 mixin 冲突（Tweakeroo 的 `MixinGameRenderer_ViewBob` 被 Iris 顶掉）。本 mod 不声明 `mixins`、不写 `breaks`、不把任何第三方 mod 作为硬依赖（模组菜单只是 `suggests`），依赖只精确到 `fabric-rendering-v1` / `fabric-lifecycle-events-v1` / `fabric-key-mapping-api-v1` 三个模块。

写入只发生在**事件**上（启动、按快捷键、换档、点按钮），绝不每帧锁定：你自己手动调回来的设置，mod 不会跟你抢。

## 已知副作用

- 关掉屏幕扭曲后，**进水里 / 进下界传送门没有画面提示**（这是关掉扭曲的代价，靠音效和小地图确认）。
- 关掉暗角后画面四周更亮、略"平"。
- 最强档会关掉附魔光效并把帧率压到 120（笔记本上稳定帧生成时间比高帧率更抗晕，但这是观感取舍，所以没放进默认档）。

## 构建

26.x 客户端已不再混淆、mod 也不再需要 refmap，所以不需要 Gradle/Loom：

```bash
# 改一下脚本开头三个变量：MC_HOME（.minecraft 目录）、PACK_DIR（含 26.2 客户端 jar 的版本目录）、JAVA_BIN（JDK 25 的 bin）
bash build.sh      # 编译 + 打包 + 静态校验，产物 out/steadicam-1.0.0+26.2.jar
bash check.sh      # 纯 Java 检查：档位表 + JSON 数字类型往返
```

`build.sh` 会从本地的 Fabric API fat jar 里抽它需要的模块 jar 到 `libs/`。`probe/` 是一个只用于测试构建的入口（`build-probe.sh`），发布产物里不含它。

## 验证到什么程度

已在一台装了 185 个 mod 的 Fabric 26.2 整合包旁，用**隔离实例**实测：mod 正常加载；标准档 6 项确实写进 `options.txt` 且未列出的项一律不动；11 项 baseline 捕获正确、连开多次不会被污染；真按 F7 走通"关闭→逐项还原→再开→重新应用"完整回路；截图确认参考线压在真实天地线上。

**未实测**：与那 185 个 mod 同场共存（发布时未装进别人的包）；配置页的实机渲染（控件签名都是对着真实 26.2 运行时编译的）。
